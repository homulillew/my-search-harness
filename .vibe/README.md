# .vibe/

本目录是项目的 **AI-assisted development workspace**。

这里的文件用于指导 ChatGPT / Codex 开发项目，
**不属于产品 runtime**。

即使未来删除整个 `.vibe/`，产品本身仍然应该能够正常安装、测试和运行。

## 目录

| 路径 | 用途 |
|------|------|
| `AI_WORKFLOW.md` | AI 协作与 GitHub 工作流 |
| `LEARNING_RULES.md` | Codex 的学习型开发与模块讲解规则 |
| `context/` | 当前项目开发背景（跨 session 恢复上下文） |
| `plans/` | 阶段计划 |
| `tasks/` | 可以直接执行的有限开发任务 |
| `reviews/` | 重要阶段 Review |
| `archive/` | 已失效的开发材料 |
